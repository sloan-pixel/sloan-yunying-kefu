## Sloan云盈客服助手

多平台多店铺电商客服整合 IM：内嵌拼多多、天猫、抖店、京东、有赞等商家客服网页，任意大模型驱动 AI 自动应答，平台转接人工、人工离线 AI 接管。

### 下载哪个

| 系统 | 文件 |
| --- | --- |
| Mac（Apple 芯片 M1/M2/M3/M4） | `Sloan云盈客服助手-版本号-mac-arm64.dmg` |
| Mac（Intel 芯片） | `Sloan云盈客服助手-版本号-mac-x64.dmg` |
| Windows 10/11（64 位） | `Sloan云盈客服助手-版本号-win-x64.exe`（安装版），或 `…-win-x64.zip`（免安装，解压后双击 `Sloan云盈客服助手.exe`） |

### 第一次打开

- Mac 提示「无法验证开发者」：在「应用程序」里右键点软件 → 打开 → 打开。提示「已损坏」：终端执行 `xattr -cr "/Applications/Sloan云盈客服助手.app"`
- Windows 提示「Windows 已保护你的电脑」：点「更多信息 → 仍要运行」

### 模型

通义千问、DeepSeek、智谱 GLM、Kimi、豆包、OpenAI、Claude、本地 Ollama（免费、不用 Key）及任意 OpenAI 兼容接口，在「设置 → 模型」里配置。不配模型也能用（只用知识库）。

完整说明见仓库 `docs/使用说明.md`，附件里的 `使用说明.html` 可离线打开。
